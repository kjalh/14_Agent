# 프로젝트 목적

학생의 이름과 점수를 등록하고, 등록된 학생 성적을 조회·분석할 수 있는 성적 관리 프로그램을 개발한다.

# 필수 기능 목록

1. **학생 성적 등록**
   - 학생 이름과 점수를 입력받아 등록한다.
   - 학생별 이름과 점수를 저장한다.

2. **전체 학생 목록 조회**
   - 등록된 모든 학생의 이름과 점수를 조회한다.

3. **평균 점수 계산**
   - 등록된 전체 학생의 평균 점수를 계산한다.
   - 등록된 학생이 없을 경우 평균을 계산할 수 없음을 안내한다.

4. **최고 점수 학생 조회**
   - 가장 높은 점수를 받은 학생의 이름과 점수를 조회한다.
   - 등록된 학생이 없을 경우 최고 점수 학생이 없음을 안내한다.

# 입력과 출력

## 입력

- 학생 이름
- 학생 점수
- 기능 선택값
  - 학생 성적 등록
  - 전체 학생 목록 조회
  - 평균 점수 계산
  - 최고 점수 학생 조회

## 출력

- 성적 등록 결과
- 전체 학생 목록
- 전체 학생 평균 점수
- 최고 점수 학생의 이름과 점수
- 입력 오류 또는 조회 결과가 없는 경우의 안내 메시지

## 데이터 예시

```text
학생 이름: 김민수
점수: 85
```

등록된 학생 목록 출력 예시:

```text
김민수: 85점
이서연: 92점
```

평균 점수 출력 예시:

```text
평균 점수: 88.5점
```

최고 점수 학생 출력 예시:

```text
최고 점수 학생: 이서연, 92점
```

# 예외 처리 요구사항

- 학생 이름이 입력되지 않은 경우 등록하지 않고 오류 메시지를 출력한다.
- 점수가 숫자가 아닌 경우 등록하지 않고 오류 메시지를 출력한다.
- 등록된 학생이 없는 상태에서 전체 목록을 조회하면 등록된 학생이 없음을 안내한다.
- 등록된 학생이 없는 상태에서 평균 점수를 조회하면 평균을 계산할 수 없음을 안내한다.
- 등록된 학생이 없는 상태에서 최고 점수 학생을 조회하면 최고 점수 학생이 없음을 안내한다.
- 점수의 허용 범위는 사용자 요구사항에 정의되어 있지 않으므로, 개발 전 점수 범위를 별도로 결정해야 한다.
- 동일한 이름의 학생을 중복 등록할 수 있는지 여부도 개발 전 정책 결정이 필요하다.
