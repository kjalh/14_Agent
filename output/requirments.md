# 프로젝트 목적

학생의 이름과 점수를 등록하고, 등록된 학생 정보를 바탕으로 다음 기능을 제공하는 성적 관리 프로그램을 개발한다.

- 전체 학생 목록 조회
- 전체 학생의 평균 점수 계산
- 최고 점수를 받은 학생 조회

# 필수 기능 목록

1. **학생 등록**
   - 학생 이름과 점수를 입력받아 등록한다.
   - 등록된 학생 정보를 저장한다.

2. **전체 학생 목록 조회**
   - 등록된 모든 학생의 이름과 점수를 조회한다.

3. **평균 점수 계산**
   - 등록된 전체 학생의 점수 평균을 계산한다.
   - 등록된 학생이 없는 경우 평균을 계산할 수 없다.

4. **최고 점수 학생 조회**
   - 등록된 학생 중 가장 높은 점수를 받은 학생을 조회한다.
   - 최고 점수와 해당 학생의 이름을 함께 표시한다.
   - 최고 점수 학생이 여러 명인 경우의 처리 방식은 별도 결정이 필요하다.

# 입력과 출력

## 입력

- 학생 이름
- 학생 점수
- 기능 선택값
  - 학생 등록
  - 전체 목록 조회
  - 평균 점수 계산
  - 최고 점수 학생 조회

## 출력

### 학생 등록

- 등록 성공 메시지
- 등록된 학생의 이름과 점수

### 전체 학생 목록 조회

- 각 학생의 이름과 점수
- 등록된 학생이 없는 경우 해당 상태를 알리는 메시지

### 평균 점수 계산

- 전체 학생의 평균 점수
- 등록된 학생이 없는 경우 평균 계산 불가 메시지

### 최고 점수 학생 조회

- 최고 점수를 받은 학생의 이름
- 최고 점수
- 등록된 학생이 없는 경우 조회 불가 메시지

# 예외 처리 요구사항

- 학생 이름이 입력되지 않은 경우 등록할 수 없어야 한다.
- 점수가 올바른 숫자 형식이 아닌 경우 등록할 수 없어야 한다.
- 점수의 허용 범위는 별도로 정해야 한다. 예를 들어 0점부터 100점까지 사용할지 결정이 필요하다.
- 등록된 학생이 없는 상태에서 평균 점수를 요청하면 안내 메시지를 출력해야 한다.
- 등록된 학생이 없는 상태에서 최고 점수 학생을 요청하면 안내 메시지를 출력해야 한다.
- 최고 점수 학생이 여러 명인 경우 모두 표시할지, 한 명만 표시할지 정책 결정이 필요하다.
