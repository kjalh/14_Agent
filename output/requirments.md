# 프로젝트 목적

학생의 이름과 점수를 등록하고, 등록된 학생 성적을 관리할 수 있는 프로그램을 만든다.

# 필수 기능 목록

1. **학생 성적 등록**
   - 학생 이름을 등록한다.
   - 학생 점수를 등록한다.
   - 이름과 점수를 함께 저장한다.

2. **전체 학생 목록 조회**
   - 등록된 모든 학생의 이름과 점수를 조회한다.

3. **평균 점수 계산**
   - 등록된 전체 학생의 점수 평균을 계산한다.
   - 등록된 학생이 없을 경우 평균을 계산할 수 없다.

4. **최고 점수 학생 조회**
   - 가장 높은 점수를 받은 학생을 조회한다.
   - 최고 점수가 같은 학생이 여러 명인 경우의 처리 방식은 별도 결정이 필요하다.

# 입력과 출력

## 입력

- 학생 이름
- 학생 점수
- 기능 선택
  - 학생 성적 등록
  - 전체 학생 목록 조회
  - 평균 점수 계산
  - 최고 점수 학생 조회

## 출력

- 등록 완료 결과
- 전체 학생 목록
  - 학생 이름
  - 점수
- 전체 평균 점수
- 최고 점수 학생의 이름과 점수
- 등록된 학생이 없을 때의 안내 메시지

# 예외 처리 요구사항

- 학생 이름이 입력되지 않은 경우 처리해야 한다.
- 점수가 입력되지 않은 경우 처리해야 한다.
- 점수가 숫자가 아닌 경우 처리해야 한다.
- 등록된 학생이 없는 상태에서 평균 점수를 요청하면 안내 메시지를 출력해야 한다.
- 등록된 학생이 없는 상태에서 최고 점수 학생을 요청하면 안내 메시지를 출력해야 한다.

## 추가 결정이 필요한 사항

다음 항목은 사용자 요청에 구체적으로 정의되어 있지 않으므로 구현 전에 결정해야 한다.

- 점수의 허용 범위
- 동일한 이름의 학생 등록 가능 여부
- 최고 점수가 같은 학생이 여러 명일 때의 처리 방식
- 프로그램 종료 후에도 데이터를 저장할지 여부
- 콘솔 프로그램인지 웹 또는 모바일 프로그램인지 여부
